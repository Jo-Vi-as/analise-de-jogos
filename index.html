🎮 Análise Global de Vendas de Videogames (Business Intelligence)

📌 O Desafio de Negócio

Fui contratado de forma fictícia por uma publicadora de jogos europeia que deseja expandir suas operações globais. O objetivo da análise foi investigar o histórico de vendas de videogames para responder a três perguntas cruciais para o time de marketing: quais gêneros são mais rentáveis, como se comporta o ciclo de vida dos consoles e as diferenças de consumo entre as regiões.

🛠️ Ferramentas Utilizadas

  • Banco de Dados & SQL: Extração e limpeza de dados (ETL).
  • Microsoft Power BI: Criação de painel interativo e modelagem de dados.

🧹 A Limpeza dos Dados (ETL em SQL)

Antes de construir o painel, tratei os dados brutos usando SQL para remover registros sem ano de lançamento ou sem publicadora.

CREATE VIEW vw_vendas_limpas AS
SELECT Rank, Name AS Nome_Jogo, Platform AS Plataforma, Year AS Ano_Lancamento...

💡 Principais Insights

  • Choque Cultural: O mercado Japonês tem uma preferência esmagadora por RPGs, enquanto o Ocidente prefere Tiro e Ação.
  • A Força da Nostalgia: Consoles clássicos como o PS2 mantiveram picos de vendas longos, abrindo janelas fantásticas para relançamentos digitais.
